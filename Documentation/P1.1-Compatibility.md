# P1.1 — Community Compatibility Data

Boreal enriches Steam entries with community compatibility evidence from ProtonDB. For a numeric Steam App ID it reads the public summary response at:

`https://www.protondb.com/api/v1/reports/summaries/<app-id>.json`

The persisted profile contains the current tier, trending and best reported tiers, confidence, score, report count, source, and fetch date. A failed refresh does not erase the last successfully persisted profile.

## Product presentation

- Library cards and rows show a compact ProtonDB tier badge.
- The game detail screen identifies the source, report count, confidence, and trend.
- Users can open the matching ProtonDB title page or browse WineHQ AppDB.
- The interface explicitly describes these results as community evidence, not a guarantee that a title works in Boreal on macOS.

ProtonDB primarily reflects Proton/Linux reports. WineHQ AppDB is exposed as a research link rather than converted into a synthetic rating because Boreal does not rely on an official stable aggregate API for it. A future Boreal-specific compatibility verdict should be based on an executed smoke test against the exact runtime, macOS version, hardware architecture, and environment configuration.

## Verification

- Deterministic integration test covers Steam metadata and ProtonDB decoding together.
- A live smoke test using the built `ProtonCompatibilityService` returned `gold`, `2029` reports, and `strong` confidence for Steam App ID `730` on 2026-08-24.
- The macOS application build and signed unit-test suite pass after the integration.
