# P1.5 — Operation progress and cancellation

## Product behavior

- Epic and GOG installs expose helper-reported percentage progress when available.
- Indeterminate phases still show a truthful stage message instead of a fabricated percentage.
- Active game work appears both on the game detail screen and in Downloads & Components.
- Cancel stops the tracked Swift task and terminates the attached `legendary` or `gogdl` process. A process that does not react to `SIGTERM` is force-terminated after two seconds.
- Cancelling a regular Windows installer also stops its Wine launcher and removes the incomplete managed environment.
- Cancelling environment preparation removes an environment created by that operation.
- Provider operation keys include both provider and external game ID so matching IDs from different stores cannot collide.

## Steam boundary

The official Steam for Windows client owns depot download state, authentication, Steam Guard, patching, and verification. Boreal reports its own client/environment preparation stages, then explicitly hands progress over to Steam instead of inventing a percentage it cannot verify.

## Validation

- `StoreOperationSupportTests` covers percentage parsing and termination of a real helper process.
- The full Boreal unit suite covers Epic, GOG, Steam for Windows, local/runtime installation, and environment recovery.
