# P0.6 — Session Recovery & Process Tree

## Contract

Boreal treats these as three independent concepts:

```text
launcher process
!=
environment session
!=
persisted application status
```

`WindowsProcessSession` describes the launcher process started by Boreal. The launcher PID and exit result are useful diagnostics, but they do not determine whether the Wine environment remains active.

`EnvironmentSessionState` describes the current prefix-scoped Wine lifecycle:

- `active` — a bounded `wineserver -w` observer remains alive after the observation window;
- `inactive` — the observer exits successfully during the observation window;
- `unknown` — the observer cannot be launched or produces an ambiguous/infrastructure failure.

The activity probe terminates only its local `wineserver -w` observer. It never invokes `wineserver -k`, `wineboot --end-session`, or another environment control operation. `waitForEnvironmentSessionEnd` is a separate API that intentionally waits for the complete Wine session.

## Recovery

A persisted `Running` value is a recovery hint, not current truth:

```text
persisted Running
  -> runtime Recovering / Needs Attention
  -> prefix probe
     -> active: Running and monitor the environment session
     -> inactive: Ready
     -> unknown: Needs Attention
```

Recovered sessions can be force-quit using only the installed runtime and `WINEPREFIX`. No historical launcher PID or in-memory executor identifier is required.

For a normal launch, launcher completion records its own exit result. Only environment-session completion can move the application from `Running` to its final inactive status.

## Acceptance criteria

- `[PASS]` launcher exit does not imply environment inactivity;
- `[PASS]` child process keeps environment active;
- `[PASS]` Boreal restart can recover active environment;
- `[PASS]` recovered environment can be force-quit without old PID;
- `[PASS]` `wineserver -k` affects only the selected prefix;
- `[PASS]` environment becomes inactive only after the wineserver session ends;
- `[PASS]` the same prefix can launch again after recovery cleanup;
- `[PASS]` `environmentSessionState` probe does not alter the active Wine session.

The executable and black-box cases live in `Tests/P0RuntimeHarness`. `Reports/latest.md` and `Reports/latest.json` contain the most recent local execution evidence.

Passing P0.6 validates the session model. It does not validate production runtime packaging, signing, Gatekeeper compatibility, dependency licensing, or distribution.
